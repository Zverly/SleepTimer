# Windows 集成验收清单

本清单仅供人工验收。自动化测试和发布审计不创建真实计划任务，不执行关机、强制关机或睡眠动作。

请在 Windows 10/11 的专用测试账户、已保存工作且可恢复的环境中执行。每项记录系统版本、账户权限、供电状态、时区和结果。

## 计划任务与时间

- [ ] 创建今天的未来时间任务，运行 `schtasks /Query /TN SleepTimer.Current /XML ONE`，确认唯一 `TimeTrigger` 的 `StartBoundary` 日期、时间和时区偏移正确。
- [ ] 创建跨午夜任务，确认界面显示完整日期；输入已过去或当前时刻时确认“安排到明天”后才创建。
- [ ] 关闭应用、结束进程、重启应用，确认任务仍可恢复；取消和调整后再次查询真实任务。
- [ ] 使用具体时刻和 30/60/90/120 分钟预设，确认目标时间按分钟精度一致。

## 电源动作

- [ ] 正常关机：确认使用正常关机参数，不包含强制关机参数。
- [ ] 强制关机：仅在无未保存数据的测试环境确认强制参数生效。
- [ ] 睡眠：确认睡眠命令符合当前 Windows 电源策略。
- [ ] 关机任务：设备进入睡眠后确认任务的 `WakeToRun` 为 `true`，并在安全窗口观察是否唤醒后关机。
- [ ] 睡眠任务：确认任务的 `WakeToRun` 为 `false`，不会为了执行睡眠任务额外唤醒设备。

## 会话、权限与设备

- [ ] 锁屏状态下确认任务行为。
- [ ] 注销后确认产品定义的任务行为，并记录是否受 `InteractiveToken` 会话限制。
- [ ] 普通用户权限下创建、调整、取消任务；记录 UAC、拒绝和错误提示。
- [ ] 分别使用交流电和电池供电验证；记录 Modern Standby 或厂商电源策略影响。

## 便携与区域环境

- [ ] 将整个便携目录移动到另一个 E 盘目录，确认启动提示清晰，任务不会继续指向旧路径或误认外部任务。
- [ ] 在中文和英文区域设置下验证创建、查询、取消和错误提示。
- [ ] 在夏令时切换前后或测试时区切换后验证目标时间、`StartBoundary` 和倒计时；记录系统时间跳变结果。
- [ ] 使用 100%、125% 和 150% 显示缩放检查窗口、按钮、托盘菜单和错误提示没有裁切或重叠。
